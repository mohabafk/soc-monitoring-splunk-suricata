# SOC Monitoring Lab — Splunk & Suricata

An academic cybersecurity lab demonstrating security monitoring,
log analysis, and basic incident response.

## Objective
Collect evidence of suspicious activity, review security alerts,
and document the response within a controlled lab environment.

## Tools Used
- Splunk — log searching and analysis
- Suricata — network intrusion detection
- Python — login honeypot
- Linux — system and log monitoring
- iptables — blocking a source IP address

## Lab Activities
1. Ran a website honeypot to record login attempts.
2. Monitored network traffic using Suricata.
3. Reviewed system logs and IDS alerts.
4. Used Splunk to search collected security events.
5. Applied a firewall rule to block an identified source IP.
6. Documented the process with screenshots.

## Skills Practiced
- Security monitoring
- SIEM log analysis
- IDS alert review
- Basic incident investigation
- Evidence collection and documentation
- Firewall-based response
